FAQ

Does it count lines or units?
Units. A line with 3 units adds 3.
How are combos counted?
A combo is one item; the products inside it are not counted again.
Is there anything to set up?
No. The count shows on every point of sale as soon as the module is installed.
Is there a user manual?
Yes. A PDF manual with screenshots, in English and Spanish, is included in the module.
Can it be translated into my language?
Yes. It ships in English and Spanish, and we can translate the module and its manual into any other language on request.
